🎓 Mi profesor de inglés

Conversaciones naturales, correcciones amables y práctica a tu ritmo

1. Preparar el profesor

La clave se introduce solo en este ordenador y se utiliza para conectar con Google. Nunca la envíes por correo ni la compartas. Abrir Google AI Studio.

Opciones del profesor

Modelo: gemini-3.8-live · Voz: Zephyr · Idioma: inglés con ayuda puntual en español.

Se guarda en este navegador para personalizar las próximas sesiones.

2. Hablar en inglés

Desconectado. Pulsa «Empezar conversación».

Al empezar, acepta el permiso del micrófono. Habla con normalidad: el profesor te escuchará y responderá en voz alta. Puedes interrumpirlo como en una conversación real.

3. Mi cuaderno de aprendizaje

Las frases transcritas se guardan automáticamente en este navegador. El profesor puede consultar un resumen de las sesiones anteriores al iniciar una conversación nueva. Si el navegador borra sus datos, también se borrará el cuaderno: utiliza «Guardar mi cuaderno» para tener una copia.

Versión de prueba gratuita · Necesita Internet, Chrome o Edge actualizados y acceso a Gemini Live API. Los límites y la disponibilidad los establece Google. La API puede rechazar la conexión aunque funcione dentro de AI Studio. No activa ningún pago.
